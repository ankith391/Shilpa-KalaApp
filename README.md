## 📌 Overview
Shilpa Kala is an Android application developed using Kotlin and Jetpack Compose to help artisans digitally showcase and brand their handcrafted products.

The app allows users to:
- Register/Login
- Upload product images
- Capture photos using camera
- Add automatic watermark and price tags
- Browse and rate artisan products

---

## 🚀 Features
- User Authentication
- Dashboard Navigation
- Camera & Gallery Upload
- Bitmap Branding
- "Handmade in Karnataka" Watermark
- Product Price Tagging
- Gallery & Rating System
- Offline Storage using Room Database

## 🏗️ Architecture

The application follows MVVM (Model-View-ViewModel) architecture for clean code separation and scalability.

UI (Jetpack Compose)
↓
ViewModel
↓
Repository
↓
Room Database
